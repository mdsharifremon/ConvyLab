# Content

One folder per page, one file per section. Each file has the same parts:

1. **Status**: Locked, Draft, or Open.
2. **Copy**: the exact words on the page.
3. **Why**: the reason for each choice.
4. **Rejected**: what was tried and dropped, so it is not tried again.
5. **Open items**: what is still missing.

## Site-wide rules

- **Positioning.** ConvyLab builds the website as a system that captures
  attention, builds connection and inspires action. This updates the message
  on the old site; it does not replace it.
- **Where the promise stops.** We bring engaged visitors and real enquiries.
  No line says we guarantee customers, rankings or AI mentions.
- **Buyers.** Consultants, mental health practices, clinics and online
  stores. No single niche on the home page; niche landing pages come later.
- **One action.** The button says "Let's talk" everywhere. It opens a short
  form on the same page, headed "Tell us what's hurting."
- **Button labels.** Three words at most.
- **Wording.** Plain language. "See how your site performs", not "track
  visitors". No tool or platform names. No prices.
- **Unproven services.** Monthly reports, enquiry filtering and AI
  visibility are described as work we do, never as results, until there is
  a client result to show.

## Standing rule: simple words (Sharif)
Use the simplest word that is true. No jargon, no method names, no "plain English" (the site is English). Prefer "regularly" to a fixed cadence like "monthly" unless the cadence is guaranteed.
